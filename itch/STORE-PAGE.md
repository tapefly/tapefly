## Description (paste into the itch text box)

```
Build a robot fly. Then find out whether it thinks.

TapeFly Workshop is a physics puzzle game about building behaviour. You get a
tiny machine insect, a board full of parts, and one job: assemble something that
finds the sugar on its own.

There is no personality slider and no hidden AI. A fly moves because of the body
you assembled and the nerves you connected. Where a wing sits changes how it
turns. Which wing an eye controls changes where it goes. A memory cell makes it
remember it has eaten. A counter makes it wait.

Then you press Fly and let go. If it crashes, rewind to the exact tick that
caused the failure, read the signal, change one wire, and fly again.

WHAT YOU GET

* 21 hand-built levels, from a two-wing reflex to memory, counting and rhythm
* 14 interchangeable parts: wings, eyes, antennae, spider hair, nose, mouth,
  memory cells, toggle cells, a metronome
* A deterministic simulation — the same design always flies the same way
* Signal timeline and failure diagnosis: scrub to the tick where it went wrong
* Chip view that turns your wiring into the real NAND gates it compiles to
* A sandbox with four arenas and almost no part limit
* Local save, save export/import, English and Simplified Chinese

CONTROLS

* Mouse or touch: place parts, wire the brain
* R: rotate the selected part
* Space: fly or replay
* Ctrl/Cmd + Z: undo

This first public demo is free and in development. No account, no wallet, no
installs — it runs in the browser. Feedback is very welcome, especially from
anyone who has never played a logic game before.
```
