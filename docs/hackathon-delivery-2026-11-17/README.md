## Submission position

TapeFly is a playable fruit fly whose complete decision layer is a NAND circuit. Players build the body, wire the senses, watch the fly act, diagnose a failure at the exact tick, change one connection, and retry. A fully checked brain can be taped out to TapeOut on X Layer.

Workshop is the only primary product for this submission. Brain Brawl, Evolution, Forage and Lineage remain supporting lab or proof experiences. Steam and AI hardware are future distribution channels.

## Current facts that must remain consistent

- The official 50-gate, 12-input, 3-output Genesis brain is live on X Layer as Circuit #2.
- Circuit #2 uses the external Sillu test processor `0x99081e1D0CE916Cd5b2c53e769DFC3B000BFE9A4`.
- Circuit #2 transaction: `0xa7ad0fd9b85e3290fbfe7d78dfba5c0ccc177d1723b3a9f6f18a1a87c937d5cd`.
- Stored bytes match the 350-byte source and all `4,096 / 4,096` eval answers match.
- A TapeFly-owned processor was created, but its NAND price was entered with the wrong unit and it is not usable for normal player purchases.
- A stateful Workshop design has a complete local/server seal proof, but it has not been taped out on X Layer.
- Future X Layer block seeds and circuit-to-circuit `REF` are not shipped.
- Steam is not published. itch is published as a wallet-free demo.

## Do not submit these claims

- “TapeFly's own processor is ready for public users.”
- “A Workshop memory circuit is already on X Layer.”
- “The daily seed already uses a future X Layer block hash.”
- “Steam or AI hardware is live.”
- “TapeFly produces physical silicon through TapeOut.”
