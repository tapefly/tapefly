00 · 一页看懂

一只电子果蝇，
参加了一场 4,096 道题的考试。

它没有眼睛，也没有肚子。它只有六个"感觉开关"：饿不饿、有没有吃的、危不危险、亮不亮、新不新鲜、上一秒在干嘛。每种开关有 4 档，全部组合起来是 4,096 种情况。每一种情况，它都要做一个决定：去吃、去躲、去探索，还是休息。

我们把 4,096 种情况一种不漏地问了它，再把它的回答和一份"参考答案"逐题对照。答对（做得一样）的有 3,494 道，所以是 85.30 分。

01 · 它站在哪

TapeOut 比谁搭得便宜。
我们比谁做得像。

先打个比方。TapeOut 像一个"电子积木市场"：大家用两种小积木搭电路（一种会算，一种会记），搭好以后可以"拍照存证"，变成一件谁也改不了的数字作品。它还会出 267 道题，比谁搭得更省。

但它不问一件事："你搭的东西，行为对不对？"一个很便宜、很省电的电路，做出来的动作也可能完全不像一只果蝇。我们补的就是这一问——给它出一张行为考卷。

我们加的：考试层4,096 道题 · 一张成绩单 · 一个能收藏的标本
↑ 看它的电路　　↓ 给它发成绩单
TapeOut 原有的：积木层小积木 · 电路图 · 存证 · 挖矿 · 钱包
比什么TapeOut我们（Onefly）
用的积木NAND / LATCH 两种小积木用同一种积木，不另外发币
出的题267 道"怎么搭更省"4,096 道"它会怎么做"
给的结果算力、奖励一张成绩单、一个标本
两家关系地基在地基上加一层考试

谁在乎"像不像果蝇"？今天几乎没人在乎，我们不装。第一位用户是我们自己：考试让"我们的电子蝇很逼真"从一句没法反驳的宣传语，变成一个可以被推翻的主张。第二位是研究果蝇的科学家：那 602 道分歧题对他们有信息量。第三位才是市场——而且是个赌注，不是承诺。

一句话：我们不跟 TapeOut 抢生意，也不假装它的买家需要成绩单。它把电路变成可以买卖的东西；我们做的是另一件事——给自己出一张卷，让"像"这个词第一次可以被推翻。

01.5 · 先看懂 TapeOut 的题库

题库不是"考你"。
题库是挖矿游戏的计分器和防作弊器。

TapeOut 是个游戏：用 NAND 门拼电路，拼得好挖 BEM。可"拼得好"怎么算？游戏要是只说"随便拼、烧门换币"，人人摆 1000 个垃圾门就刷爆了。于是官方出了 267 道作业题（组合 209 + 时序 58，官方自报）：造一个加法器、造一个"八位全零检测器"、造一个"八选一开关"……

类比：一个高尔夫球场加排行榜。267 个洞，每洞有标准杆；你打一杆（交一个电路），合约自动量你离洞多远；别人怀疑你作弊，举证一条算错的就能把你踢出榜。

但这台机器能转，全靠它的题"有标准答案、有标准杆"。逻辑题天生如此：与非门跑四条向量就知道对不对，成本能从网表直接算出来，纪录可以被破。

TapeOut 的 267 道题我们的 4,096 道题
考什么算得对不对（功能正确）像得像不像（行为接近）
标准答案有，且唯一（真值表）没有，要生物学家人工写，还可能是错的
标准杆有，C_ref 上链冻结没有——不存在"最像的蝇"
防作弊合约自动跑向量 + 任何人可举证撤销判卷程序公开 + 你自己重算一遍
纪录最优首创，C 严格更小才能夺榜没有榜——只有"更能被推翻"

所以我们的卷没法抄它：行为题没有真值表、没有标准杆、没有纪录可破。能借的只有它的方法——出题、计分、打假——答案那一半，只能自己写。这就是下一章要讲的东西。

02 · 这不是一只宠物

一只考完不算什么。
要办成一所学校。

如果只是我们养了一只电子果蝇，那没什么稀奇。真正有用的是：把"怎么考"变成一套谁都能用的办法。以后蜜蜂、蚂蚁、蟋蟀……都可以来考同一套卷子。每来一个新动物，只要交两样东西：一张电路图和一份参考答案。

出题的人交一张电路图 + 一份参考答案，就能加一个新动物
验卷的人任何人拿电脑重算；算不出同样的分数，成绩单作废
玩家自己上手玩；分数来自回放，不是自己说了算
矿工继续在 TapeOut 挖矿；我们不抢他们的算力

案例库（数字标本馆）每多一只动物，就多一件可以比较的标本；以后谁想证明自己的电子蜜蜂像蜜蜂，都得先来这里排个位置

这个循环里最值钱的不是某一只蝇，是案例库：每复刻一篇论文里的神经回路，就多一件带日期、带分数的标本。标本越多，后来的人越绕不开你——因为大家比的都是同一张卷子。

说实话：现在只有 1 只动物（果蝇），案例库只有 1 件，标本还没存到链上（等一颗积木的钱）。上面画的是以后会长成什么样，不是已经做完了。

03 · 它怎么长大

每多一个感觉，题目就翻 4 倍。

为什么是 4 倍？因为每个感觉有 4 档（0、1、2、3）。6 个感觉就是 4×4×4×4×4×4 = 4,096 道题。再加一个感觉，就再乘 4，变成 16,384 道。

4 个感觉256 道
5 个感觉1,024 道
6 个 · 现在4,096 道
7 个感觉16,384 道
8 个感觉65,536 道

条形是按比例缩着画的。电脑算 65,536 道题也就一眨眼——所以"题多"根本不是问题。

什么在变大怎么变大现在要紧吗
考卷每多一个感觉 ×44,096 道电脑算得完，不要紧
大脑跟着"规则几条"长7 条规则 → 50 个积木跟题目多少无关
成绩单盖一个防伪章几秒钟不要紧
加一个新动物要写一份靠谱的参考答案1 只真正花时间的是这个

所以"能长大"不是指题目多，而是：考试的办法、成绩单的格式、验算的程序，只写一次；每加一个新动物，只要写一份参考答案。真正难的就是这份答案——它是科学判断，不是写代码。所以我们把它公开、标上"草稿"（第 0 版）：谁做得更好，就出第 1 版，全部重考。护城河不是代码，是"公开的答案 + 公开的卷子 + 公开的成绩单"。

为什么这一层以前是空的？因为 TapeOut 的 267 道题默认"功能已经对了，只比省不省"。可一旦电路要做"行为"——机器人怎么躲、AI 怎么选、游戏里的角色怎么反应——"省"不能代替"对"。现在有人在卖"AI 的宪法"，但官网上连一张电路图都没有；等他们真做出来，第一件事就是被这套卷子考。

说清楚：我们不发行代币、不参与挖矿分钱、不承诺收益。我们用的还是 TapeOut 的地基，产出的是成绩单和标本。所以不是抢生意，是加一层。

05 · 先看它的大脑

它的脑子里，只有 50 个小积木。

这些小积木叫 NAND，你可以理解成"两个开关都打开时，灯反而灭"的小零件。它们不会记事，所以"上一秒在干嘛"也要当成一个感觉输进去。整个大脑没有记忆，只有一套"如果……就……"的规则。

有吃的吗没有一点不少很多
危险吗安全有点很危险快跑
亮不亮黑有点光亮很亮
新不新鲜见过有点新很新从没见过
饿不饿不饿有点饿很饿
上一秒在吃饭在躲在看在休息
这就是第 790 道题 规则：很饿 + 有吃的 去吃饭 →

一道题 = 六个感觉各选一档。全部选完，就是 4,096 道题里的第 790 道。下面 FIG 2 的地图上，我们把它圈了出来。

#规则输出
1很危险躲开，并发出"跳"
2有点危险，而且刚躲过 / 不太饿躲开
3很饿，而且有吃的去吃
4吃的很多去吃
5正在吃，而且还有吃的继续吃
6有没见过的东西去看看
7刚在休息，而且不太饿继续休息
其他都不符合亮就看看，黑就休息

三条要老实说的话：① 真果蝇那两条视觉神经，我们合成了一条；② "该跳就跳"是 100%，但那是因为我们和参考答案读的是同一批论文，不是我们复刻了真大脑；③ 参考答案里的数字是我们自己定的，不是量出来的。

06 · 再看考卷

4,096 道题，一道都没漏。

下面这张图，每一个小格子就是一道题。颜色表示它决定做什么：红的是躲、金的是吃、青的是看看……你看颜色是一大片一大片的，说明它不是把 4,096 道题死记下来，而是按几条规则分类。

那"参考答案"是谁写的？是我们写的一份草稿。它也有版本号（第 0 版）、状态（草稿）和防伪码。我们把它公开，就是让所有人看到：我们到底拿什么在比。

为什么不随便抽 100 道题？因为全部跑完，就没法"挑好看的题"。50 个积木也小到一个人能从第一块看到最后一块。别人做 661 个零件——零件多不等于像，只等于没人能从头看到尾。

07 · 再看成绩单

85.30 分，是这么算出来的。

一份真实的成绩单 · 第 1 号
85.30 / 100

4,096 道题里，有 3,494 道和参考答案做得一样。3,494 ÷ 4,096 = 0.8530，也就是 85.30 分。这不是"及格证"，只是"和我们的草稿答案有多像"。

3,494做得一样
602做得不一样
2,048该躲的全躲了
0次乱躲
防伪码 0c24da2421f0a33a0942d4d7846d5fa0f7fd1f12c33c9ee59bce5c1b204422d9

最得意的数字是"2,048 道危险题全躲对，0 次乱躲"。但我们不把它算成"复刻了真大脑"——因为我们和参考答案读的是同一批论文，这项本来就该对。它只证明一件事：这只蝇在危险面前不会犯傻。

08 · 那 602 道怎么办

602 道"不一样"，其实是 602 个好玩的问题。

哪一类题不一样的比例说白了
吃饱了还追不追75%两种做法在真果蝇身上都见过，没有标准答案。
黑屋子里有新鲜味道47%我们的蝇敢去；参考答案说"先有光再说"。
好奇和饿，哪个更要紧47%这是个可以争论的实验设计问题。
饿了 + 有吃的，怎么算43%两套写法不一样，算出来的结果就不一样。

所以这 602 道不是"错题"，是 602 个可以研究的问题。成绩单里还留了 16 道具体的题，每一道都能单独重算。哪天有研究果蝇的专家愿意来改答案，这 602 道就是起点。

09 · 你自己也能验

你也可以自己验。算不出 85.30，就是我们作弊。

不用相信我们。打开电脑，把下面几行复制进去，它会重新判 4,096 道题，再写出一张新的成绩单。

# 第一步：安装需要的东西
npm install

# 第二步：重新判 4,096 道题，写一张新成绩单
npx tsx scripts/calibrate.ts

# 第三步：自动检查，分数必须还是 85.30
npm test

# 第四步（可选）：把整个项目从头检查一遍
npm run check

你只要看两个地方：分数还是不是 0.8530，防伪码还是不是 0c24da24…422d9。对不上，就是我们错。

给完全没写过代码的朋友：npm 就像手机上的"应用商店"，npx tsx 是"把某个程序跑一次"。上面四行做的事，说白了就是：装工具 → 重新判卷 → 对答案 → 全项目复查。你不用看懂每个词，只要看到最后两行一样就行。

11 · 我们不做的事

我们不做什么。这一节，决定你信不信前面十节。

  • 不发币、不承诺赚钱。生态里的 BEM 是别人的币，价格一个月里从 18 涨到 92 又掉到 40；我们只用几块钱体验，不重仓，也不给投资建议。
  • 不说它"活着"。它是一堆会算的开关，不是生物，不是 AI。
  • 不说 85.30 是"及格证"。答案是我们自己写的草稿；成绩单上就印着"这是校准，不是认证"。
  • 不把"以后要做"说成"已经做完"。没做的就写没做。
  • 不假装有需求。TapeOut 的买家要的是挖矿，没有一个人等着"像不像果蝇"的体检报告。我们不说那是市场空白——第一位用户是我们自己，考试是为了让这个项目可以被推翻。
  • 不发一个你没法自己验的分数。这是最低要求，也是我们唯一真正的护城河。
11.5 · 我们的愿景

今天是一只果蝇。
明天是一层"行为的考场"。

使命
现在在做的		给"像不像"立一把尺子：出一张 4,096 题的卷，写一份参考答案，发一张任何人都能重算的成绩单。第一把尺子已经造出来了（85.30）。
愿景
想要的世界		每只说自己"像"的电路——果蝇、蜜蜂、将来的机器人小脑——都能来排队考试，成绩单互相可比。"像"从一个形容词，变成一个数字。
赌注
相信但未被证明的		会动的机器会越来越多，"能被检查的行为"迟早比"更省的门"更值钱。今天没人出这张卷，不是因为它难，是还没人非它不可。

先把话说小：今天做完的只有一只果蝇、一份草稿答案、50 块积木。但把它背后的方法抽出来，会长成一个比"果蝇"大得多的东西——一层给"行为"打分的公共设施。

打个比方。TapeOut 把"造电路"这件事标准化了：积木、存证、挖矿、市场。我们想在它上面标准化另一件事："这个电路的行为，到底对不对、有多对"。它像一座考试院，不是一所学校——我们不自己养所有动物，我们只负责出卷、判卷、发一张谁都能复算的成绩单。

我们想去的：行为层出卷 · 判卷 · 第三方成绩单 · 可比较的标本
↑ 考行为　　↓ 借用它的地基
TapeOut 已经在的：电路层积木 · 电路图 · 存证 · 挖矿 · 市场（5,519 件在售）
↑ 再往下
更底层：链谁都改不了、谁都能读的账本

为什么这层可能值钱——注意，是赌注，不是承诺。世界也许正在往"会动的机器"上走：机器人、无人车、游戏角色、AI 代理。如果有一天"会动的东西"真的要互相买卖，那最缺的大概不是算力，是能被检查的行为。今天没人出这张卷，不是因为它难，是因为还没人非它不可。我们先把尺子做便宜、做公开——赌对了，尺子就是基础设施；赌错了，一把尺子也亏不到哪去。

可以长出去的方向怎么长（用的是同一套办法）现在到哪了
更多动物蜜蜂、蚂蚁、蟋蟀……每个只要交一张电路图 + 一份参考答案计划
机器人小脑避障、觅食、跟随，换成机器人的"感觉"，还是 4,096 道题的模板计划
第三方成绩单别人做的电路也能来排队考试，我们只出卷、不站队——但前提是有人愿意来赌注
可比较的标本库每份成绩单都带日期、带防伪章，攒成一张参照表——先攒自己的第 1 件已上链

这四件事今天一件都没做完。它们的共同点是：不需要重写系统，只需要再写一份参考答案。这也是我们说"扩展性强"的真正意思——难的不是代码，是那份答案背后的科学判断；所以它慢，但也正因为慢，别人很难一夜之间抄走。

一句话的远方：让"它像不像真的"从一句宣传语，变成一个任何人打开电脑都能重算的数字。今天这个数字是 85.30，属于一只果蝇；以后它应该属于每一个说自己"像"的电路。

12 · 我们发什么：NFT 与 token

发 NFT（标本），不发币。

先说结论：我们铸 NFT，不发行新代币——结算直接用生态里已有的 BEM，不另起炉灶。机制上参考了 stonkrobotics.xyz 的玩法（4,444 台人形机器人、0–100 分上链、答题最高分免费铸），它几乎是为"考试 + 收藏"量身定做的模板——但有一个地方我们比它硬，后面说。

TapeOut 生态里已有的它是什么我们对应发什么

电路（在售 5,519 件）一份上链的网表，可以买卖果蝇 = 一份 50 NAND 网表，流片后铸成「标本 NFT」

诚实边界：不发币、不做金融层（不搞借贷、质押、分红那一套）、不承诺收益。标本 NFT 是"带成绩单的收藏品"，不是证券，不对应任何公司的股权。

13 · 我们对生态的贡献，以及怎么赚钱

补一层，不抢一层。钱的事，一句谎都不说。

对 TapeOut 生态的贡献，三条：

  • 补一层，不抢一层。267 道题默认"功能已对，只比省不省"；我们用同一套地基证明：电路还能被问"行为对不对、有多对"。不建平行链，不加一层楼。
  • 第一个非游戏化样板。生态现有用途几乎全是挖矿和市场交易。电子蝇是第一个"TapeOut 电路做可验证行为"的完整案例——设计、流片、判卷、复算，一条龙跑通，后面的蜜蜂、蚂蚁、机器人小脑照抄模板。

附 · 名词小抄

看不懂的词，看这里。

词大白话
NAND（与非门）"两个开关都打开时，灯反而灭"的小零件。它只会算，不会记。
LATCH（锁存器）会"记住"的零件。我们一个都没用，因为大脑只要会算。
流片把电路图"烧"成一件谁也改不了的作品，存在链上。
考卷（4,096 题）6 个感觉、每个 4 档，所有组合都问一遍。
参考答案我们自己写的一份"标准做法"，上面标着"草稿"。
防伪码（哈希）给文件盖的章。内容改一个字，章就完全变了。
复算别人拿同样的题和答案再算一遍，必须得到同一个分数。
挖矿（PoD）TapeOut 的发奖励办法：设计越省，分得越多。
BEMTapeOut 生态里的代币 / 奖励，是别人的，不是我们的。
