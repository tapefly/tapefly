> TAPEFLY · 50 颗 NAND · 4,096 种处境 · 一份谁能重算的成绩单

四支团队都说自己养的那只最像真果蝇。四家都是自己出题、自己批卷——像四所学校各自发毕业证。

## 0 · 先读这一页：四档数字

| 档 | 是什么 | 本文里的例子 | 怎么对待 |
| --- | --- | --- | --- |
| **A · 文献** | 已发表研究里的数字 | 果蝇逃逸回路由 LC4/LPLC2 驱动，合计约占 Giant Fiber 视觉输入的 **99.6%**（Ache et al. 2019）；决策窗口约 **0.1 秒** | 只引原论文，不叠加自己的解释 |

## 1 · 主张

一份排行榜若按观点排序，排的其实是写观点的人。一份答案不公开的考卷，是一场你无法审计的抽奖。

养蝇圈现在正好在这个位置。**四家的分数全是自己出题、自己批卷**；最接近独立评价的一句话，是第三方评级站对其中体型最大那家的评语："没有评价——因为没有人细读到能给它盖章。"

替代方案不是"再养一只更像的蝇"，而是一张**可发布的卷子**：处境集合固定、参考行为写成文字、判分只用整数比较、复算只需一条命令。

我们做了这张卷子，并把第一份成绩单钉在一个 32 字节的封印上。这个主张可以很小：**50 颗门、4,096 个字、一个分数、一个封印**。其余都是下游。

## 1.5 · 先看懂 TapeOut 的题库（大白话）

TapeOut 是个游戏：用 NAND 门拼电路，拼得好挖 BEM。可"拼得好"怎么算？游戏要是只说"随便拼、烧门换币"，人人摆 1000 个垃圾门就刷爆了。于是官方出了 **267 道作业题**（组合 209 + 时序 58，官方自报）：造一个加法器、造一个"八位全零检测器"、造一个"八选一开关"……

**类比：一个高尔夫球场加排行榜。**267 个洞，每洞有标准杆；你打一杆（交一个电路），合约自动量你离洞多远；别人怀疑你作弊，举证一条算错的就能把你踢出榜。

题库的三个用处：

1. **有标准答案**——每道题一张"输入→输出"表，对错精确判定，不用吵；
2. **有标准杆**——官方先做一个参考实现，成本冻结在链上（C_ref）；你比它小、比它浅，算力加成（最高 4 倍）；
3. **能抽检打假**——开挖时合约现场抽 ≥3 条官方向量；谁提交一条你算错的向量，无需质押即可撤销你的矿机。

**一句话：题库让"挖矿"从"烧门换币"变成"打比赛"。**

但这台机器能转，全靠它的题"有标准答案、有标准杆"——逻辑题天生如此。所以两套题库根本不同：

| | TapeOut 的 267 道题 | 我们的 4,096 道题 |
|---|---|---|
| 考什么 | 算得对不对（功能正确） | 像得像不像（行为接近） |
| 标准答案 | 有，且唯一（真值表） | 没有，要生物学家人工写，还可能是错的 |
| 标准杆 | 有，C_ref 上链冻结 | 没有——不存在"最像的蝇" |
| 防作弊 | 合约跑向量 + 任何人可举证撤销 | 判卷程序公开 + 你自己重算一遍 |
| 纪录 | 最优首创，C 严格更小才能夺榜 | 没有榜——只有"更能被推翻" |

我们的卷没法抄它：行为题没有真值表、没有标准杆、没有纪录可破。能借的只有方法——**出题、计分、打假**——答案那一半只能自己写。

## 2 · 这只蝇

**大脑**：一张 **50 颗 NAND、0 颗 LATCH** 的组合逻辑网表，12 位输入、3 位输出。网表哈希 `c1d4142ae84693f99c7c991a1178b9ba38e337e05cdb50f7d014f57d1fe264e7`。

**为什么是 4,096 题**：六个感觉，每个 **4 档（2 位）**——

- 食物 `f`、威胁 `t`、光 `l`、新奇 `n`、饥饿 `h`、上一个行为 `p`

合起来 12 位，**4⁶ = 2¹² = 4,096** 个输入字。每一个字，都是一只蝇可能面对的一个处境。（它不是一个抽样：整个输入空间被穷举了。）

**行为**：两条反射规则写成七条按优先级排列的规则，先命中先决定：

| # | 规则 | 输出 |
| --- | --- | --- |
| 1 | 威胁 ≥ 2 | 避让，**Giant Fiber 放电** |
| 2 | 威胁 ≥ 1，且（上一步在避让，或饥饿 < 2） | 避让 |
| 3 | 饥饿 ≥ 3 且食物 ≥ 1 | 靠近 |
| 4 | 食物 ≥ 3 | 靠近 |
| 5 | 上一步在靠近，且食物 ≥ 2 | 继续靠近 |
| 6 | 新奇 ≥ 2 | 探索 |
| 7 | 上一步在休息，且饥饿 < 3 | 休息 |
| 默认 | 其余 | 有光则探索，黑暗则休息 |

输出是 2 位行为（靠近 / 避让 / 探索 / 休息）+ 1 位"GF 是否放电"。

**大脑之外还有身体**：`sim/engine.ts` 里是一只带代谢、感官和外部世界的蝇；但考卷只考大脑——给定 12 位输入，输出 3 位。这是刻意的边界：**行为可以考，身体不能替它答题。**

## 3 · 大脑不是比喻

真果蝇的逃逸反应有一条很窄的通路。Ache et al. 2019 的突触计数里，两个视觉神经元占掉了 Giant Fiber（逃逸跳的指令细胞）视觉输入的 **≈99.6%**：

- **LC4**：对视角速度敏感，2,442 个突触；
- **LPLC2**：对"逼近"敏感——一个随着靠近而变大的形状，1,366 个突触。

影子压下来到起跳，真蝇的决策窗口大约 **0.1 秒**。

这只电子蝇没有假装拥有那 13.9 万个神经元（FlyWire 2024 的连接组数字）。它做的是把那条通路压成一张能完整读完的网表：**一个威胁通道、两个阈值、50 颗门、0 个锁存器**。纯组合逻辑意味着它没有"记忆单元"——上一秒的状态是被编码进输入的，不是被存下来的。

**三条如实写下的限制**（原话也在成绩单的 `note` 里）：

1. 12 位布局把 LC4 和 LPLC2 **合并成一个威胁通道**，这不是两通道仿真；
2. GF 的召回率 1.0，反映的是"我们的第 1 条规则和参考实现读的是同一批文献"，**不是**"电路复刻了连接组"；
3. 参考实现里的常数是**编辑判断，不是实测**。

## 4 · 考卷

考卷叫 `t1-full`：4,096 行，编码是 `FFW-NAND/1` 的 12 位字布局。

参考行为来自一份**写明的草稿**，不是黑箱：

| 项 | 值 |
| --- | --- |
| 参考版本 | `FLY-LIF/0`，状态 `draft` |
| 参数 | `LOOM=[0,6,22,60]`、`TH_GF=20`、`TH_FEED=4`、`TH_N=2` |
| 参考哈希 | `8caa53059b06eb7ea7dc88c927b84b718bc3471ebe789b9e4bdfa9909641d4f6` |

判分只有一件事：**逐字比较**。4,096 个输入字，网表输出与参考行为一致多少次，就是多少分。没有加权、没有"综合印象"、没有人类评审。

为什么要把 4,096 题全跑完，而不是抽 100 题？

- 空间小到可以**穷举**，穷举就没有抽样误差，也没有"挑好看的题"的空间；
- 50 颗门小到**一个人可以从头读到尾**——考卷的每一题，都能追到网表里哪几颗门决定的；
- 圈里最大的那只有 661 个零件。大不等于像，只等于**没法被完整审计**。

## 5 · 成绩单

**85.30 / 100**。3,494 题一致，602 题分歧。成绩单封印：

```
0c24da2421f0a33a0942d4d7846d5fa0f7fd1f12c33c9ee59bce5c1b204422d9
```

分歧不是均匀撒开的，它**成片出现**——有片，就有原因：

| 规则 | 行数 | 分歧 | 分歧率 |
| --- | ---: | ---: | ---: |
| 逃逸 escape | 2,048 | 0 | **0%** |
| 危险 danger | 640 | 0 | **0%** |
| 进食 feed | 336 | 144 | 43% |
| 诱饵 lure | 240 | 112 | 47% |
| 追逐 pursue | 64 | 48 | **75%** |
| 好奇 curious | 384 | 180 | 47% |
| 休息 rest | 96 | 32 | 33% |
| 默认 default | 288 | 86 | 30% |

最硬的一块是**生死题**：2,048 道"该跳"的处境，全部跳了；另外 2,048 道"不该跳"的处境，**一次都没乱跳**（tp=2048 / fp=0 / fn=0 / tn=2048，召回与精确率都是 1.0000）。

但我们不把这块算成"复刻了真大脑"的功劳。它只证明一件事：**体检合格**——这只蝇在该逃的时候一定逃。它和参考答案读的是同一批文献，所以这项 100% 本来就是预期内的。

**85.30 是什么，不是什么**：

- 是：这只 50 门网表与一份写明的草稿参考，在全部 4,096 个处境上的**距离**；
- 是：任何人用同一条命令可以重现这个距离；
- 不是：认证、不是"通过了行为学考试"、不是"像真果蝇"的证明。

成绩单自己就这么写着：**"Calibration, not certification."** 这句话印在证书里，不藏在脚注。

## 6 · 602 题，是 602 个问题

分歧率最高的三片，每一片都能翻译成人话：

1. **"撑着了还追吗？"**（追逐题 75% 分歧）——行为学上两种策略都真实存在：吃饱后停止追逐，或者继续囤积。我们的蝇选择继续，参考实现选择停。
2. **"黑屋里的新味道"**（诱饵题 47%）——我们的蝇在没有光的时候也敢去闻新东西；参考实现要求先有光。
3. **"好奇该不该压过饥饿"**（好奇题 47%）——新奇信号与进食信号的优先级，是一个可以争论的实验设计问题。

所以 602 不是"错题本"，更像一份**给行为学家的提问清单**：如果哪一天有人愿意重做参考实现，这 602 行就是起点。成绩单里还留了 16 个逐题样本（`disagree_examples`），每一行都能单独复算。

## 7 · 可复算

这个包里没有 `node_modules`，也没有 lockfile，所以先装依赖：

```bash
npm install
npx tsx scripts/calibrate.ts     # 重新判 4,096 题，写出成绩单
npm test                         # 把成绩单的语义钉死
npm run check                    # typecheck + tests + lineage --check + build
```

复算成功的判据只有两个：`calibration/ffw-nand-1.json` 里 `result.agreement` 仍是 `"0.8530"`，`seal` 仍是上面那串。**算不出来，就是我们作弊。**

考试这个动作本身也被测了：`tests/calibration.test.ts` 与 `tests/reference.test.ts` 把"85.30 必须重现"写成断言，而不是写成希望。

## 9 · 定位：行为协议

TapeOut 是**电路协议**：代币当晶体管，网表流片成 NFT，官方出 267 道工程题，考的是"你的实现比参考省多少成本"。

Onefly 想做的是**行为协议**：同一批晶体管、同一种流片，但考的是另一件事——

> **TapeOut 不朽化电路。Onefly 不朽化智能。**
> **官方考"电路多便宜"，我们考"电路多聪明"。**

七组镜像，每一项都标了真实状态：

| TapeOut | Onefly 镜像 | 状态 |
| --- | --- | --- |
| 晶体管（NAND/LATCH 统一规格） | 基因：决策常数溯源到真实论文 | ✅ |
| 电路网表 | 大脑：50 门，4,096 处境全覆盖 | ✅ |
| 流片（NFT 永久固定） | 生命流片：大脑上链，永不死亡 | 🔨 等买料 |
| 题库 267 题（考成本） | 考卷 4,096 题（考行为）——全网首创 | ✅ 已判卷 85.30 |
| 处理器（镇子） | 生态位：一物种 = 一大脑 + 一考卷 | 🗺️ 蓝本 |
| 容器（ERC-6551） | 身体 + 日记：专属钱包 + 每日档案 | 🔨 阶段 2 |
| 挖矿产值 | 判卷机产值：不烧电，烧"处境" | 🗺️ 阶段 3 |

五层塔从下往上：**证据层**（常数有出处）→ **电路层**（50 门）→ **验证层**（4,096 题，首创）→ **生命层**（流片 + 身体 + 日记）→ **生态层**（判卷机、数字标本馆、行为流片标准）。

三幕：最小可验证智能 → 数字标本馆（蜜蜂、蚂蚁、蟋蟀排队）→ 判卷机成为标准。

宏大不等于吹牛，靠三条铁律：**每条宣言挂一件可复算的实证；用 TapeOut 的电路和容器，验收标准借用它的；阶段 0/1 的总成本控制在几块钱内。**

## 10 · 我们不做什么

- **不发币、不做收益。** 这个项目里没有代币、没有质押、没有"玩赚"。生态里的 BEM 是**别人的**代币，官方数字全部是自报，月内从 18 到 92 再到 40——我们只用小钱体验，不重仓，也不提供投资建议。
- **不说它"活着"。** 它是一张会算的网表，不是生物，不是模型，不是"AI agent"。
- **不把 85.30 说成认证。** 参考实现是我们自己写的草稿，常数是编辑判断；这句话写在成绩单里，也会一直写下去。
- **不拿蓝图冒充进度。** 上面表里的 🔨 和 🗺️ 就是没做完的部分，不会出现在"已完成"里。
- **不假装有需求。** TapeOut 的买家要的是挖矿，没有一个人等着"像不像果蝇"的体检报告。我们不说那是市场空白——**第一位用户是我们自己，考试是为了让这个项目可以被推翻。**
- **不发一个没有复算命令的分数。** 这是最低要求，也是这个项目唯一真正的护城河。

## 11 · 我们想去的远方（深度愿景与扩展性）

**先把话说小**：今天做完的只有一只果蝇、一份草稿答案、50 块积木。

**愿景三行**：

| | 内容 |
|---|---|
| **使命（现在在做的）** | 给"像不像"立一把尺子：出一张 4,096 题的卷，写一份参考答案，发一张任何人都能重算的成绩单。第一把尺子已经造出来了（85.30）。 |
| **愿景（想要的世界）** | 每只说自己"像"的电路——果蝇、蜜蜂、将来的机器人小脑——都能来排队考试，成绩单互相可比。"像"从一个形容词，变成一个数字。 |
| **赌注（相信但未被证明的）** | 会动的机器会越来越多，"能被检查的行为"迟早比"更省的门"更值钱。今天没人出这张卷，不是因为它难，是还没人非它不可。 |

**再把话说大**：把它背后的方法抽出来，会长成一个比"果蝇"大得多的东西——**一层给"行为"打分的公共设施**。

**谁在乎"像不像果蝇"？今天几乎没人在乎，我们不装。**第一位用户是我们自己：考试让"我们的电子蝇很逼真"从一句没法反驳的宣传语，变成一个**可以被推翻的主张**。第二位是研究果蝇的科学家：那 602 道分歧题对他们有信息量。第三位才是市场——而且是个**赌注**，不是承诺。

打个比方：TapeOut 把"造电路"标准化了（积木、存证、挖矿、市场，目前在售 5,519 件）。我们想在它上面标准化另一件事——**"这个电路的行为，到底对不对、有多对"**。它像一座**考试院**：我们不自己养所有动物，只负责出卷、判卷、发一张谁都能复算的成绩单。

**为什么这层可能值钱——注意，是赌注，不是承诺。**世界也许正在往"会动的机器"上走：机器人、无人车、游戏角色、AI 代理。如果有一天"会动的东西"真的要互相买卖，最缺的大概不是算力，是**能被检查的行为**。今天没人出这张卷，不是因为它难，是因为还没人非它不可。我们先把尺子做便宜、做公开——赌对了，尺子就是基础设施；赌错了，一把尺子也亏不到哪去。

| 可以长出去的方向 | 怎么长（同一套办法） | 现在到哪了 |
|---|---|---|
| 更多动物 | 蜜蜂、蚂蚁、蟋蟀：每个交一张电路图 + 一份参考答案 | 计划 |
| 机器人小脑 | 避障、觅食、跟随，换成机器人的"感觉"，还是 4,096 道题的模板 | 计划 |
| 第三方成绩单 | 别人做的电路也来排队考试，我们只出卷、不站队——但前提是有人愿意来 | 赌注 |
| 可比较的标本库 | 每份成绩单带日期、带防伪章，攒成谁都绕不开的参照表 | 第 1 件已上链 |

这四件事今天**一件都没做完**。它们的共同点是：不需要重写系统，只需要**再写一份参考答案**。这就是"扩展性强"的真正意思——难的不是代码，是那份答案背后的科学判断；所以它慢，也正因为慢，别人很难一夜之间抄走。

> 一句话的远方：让"它像不像真的"从一句宣传语，变成一个**任何人打开电脑都能重算的数字**。今天这个数字是 85.30，属于一只果蝇；以后它应该属于每一个说自己"像"的电路。

## 12 · 我们发什么：NFT 与 token

**发 NFT（标本），不发币。**结算直接用生态已有的 BEM，不另起炉灶。机制参考 stonkrobotics.xyz（4,444 台人形机器人、0–100 分上链、答题最高分免费铸）——它几乎是为"考试 + 收藏"量身定做的模板，但有一个地方我们比它硬。

| TapeOut 生态里已有的 | 它是什么 | 我们对应发什么 |
|---|---|---|
| 处理器（三种"镇子"） | 流片和挖矿的地方（Behemoth / TapeOut / Genesis） | 租用，不自己造——考场是人家的 |
| 电路（在售 5,519 件） | 一份上链的网表，可买卖 | 果蝇 = 一份 50 NAND 网表，流片后铸成「标本 NFT」 |
| 容器 | 给电路一个账户 | 给每只果蝇一个身体 + 性格日记 |
| 晶体管（NAND / LATCH） | 消耗品，按颗买、流片时烧掉 | 造果蝇的原料——50 颗 NAND 是它全部家当 |
| $BEM | 生态挖矿奖励代币 | 我们的结算层（判卷费、市场计价用它，不新发币） |
| 空投 | 生态活动 | 参与，不承诺 |

**最关键的一个机制，直接借 STONKROBOTICS 的 best plan：**它每 20 分钟开一个窗口，你把考题粘给自己在用的 AI，交方案回去，**窗口截止时分数最高的人免费拿一台机器人**——不是先到先得，是考得最好才拿。换成我们的东西：

窗口开启（一道行为考题）→ 你去作答（调你的电路或 AI）→ 判卷机打分（0–100，公开可复算）→ 最高分免费铸（标本 NFT 上链）→ 下一道题，永远循环。

| STONKROBOTICS 的机制 | 它怎么干 | 我们怎么对应 |
|---|---|---|
| 免费 mint | 每窗口答题，最高分白拿 | 一模一样：考 4,096 题，分高免费铸 |
| 付费 mint | 统一 5 USDC，先到先得 | 直接买已考过的果蝇，价格市场定 |
| 分数上链 | 0–100 分永久记录 | 85.30 + 防伪码，且可复算 |
| ERC-6551 绑定钱包 | 每个 NFT 自带账户 | 对应 TapeOut 的「容器」：身体 + 日记 |
| 稀有度 | 开盲盒抽 tier | 分数档 + 行为特征——不是随机，是考出来的 |
| Fleet Finance（借贷/质押/分红） | NFT 当抵押品 | **不做。**NFT 是标本收藏品，不是证券 |

**我们比它硬的地方：**STONK 的分数来自"某个 AI 临时写的一份方案"，换人换模型重跑就变了，没法复算；我们的分数来自固定的 4,096 道题 + 公开判卷程序，任何人一条命令重跑，要么得到同一个 85.30，要么证明我们错了。同样是"考分铸 NFT"，我们的是可审计的。

**诚实边界：**不发币、不做金融层（不搞借贷/质押/分红）、不承诺收益。标本 NFT 是"带成绩单的收藏品"，不是证券。

## 13 · 我们对生态的贡献，以及怎么赚钱

**对 TapeOut 生态的贡献，三条：**

1. **补一层，不抢一层。**267 道题默认"功能已对，只比省不省"；我们用同一套地基证明电路还能被问"行为对不对、有多对"。不建平行链。
2. **第一个非游戏化样板。**生态现有用途几乎全是挖矿和市场交易；电子蝇是第一个"TapeOut 电路做可验证行为"的完整案例（设计→流片→判卷→复算），后面的蜜蜂、蚂蚁、机器人小脑照抄模板。
3. **公共判卷程序。**开源、一条命令复算，第三方也能来排队考试。

**怎么赚钱——诚实三层：**

| 层 | 内容 |
|---|---|
| 今天 | 收入 = 0，不假装有。最近一笔真实可能的钱：X Layer × TapeOut 黑客松（10 万 USDT 池：一等 1 名 20,000 / 二等 5 名各 10,000 / 三等 5 名各 6,000，官方自报） |
| 参赛可写的模式 | ① 出卷/判卷服务（按次收链上费用）；② 成绩单数据与 API；③ IP 游戏化。全部标"计划"，一个都没开始做 |
| 长期（赌注） | 若"可检查的行为"真被交易，尺子就是基础设施；赌错只亏一把尺子 |

**按黑客松评审标准自评：**

| 评审标准 | 诚实回答 |
|---|---|
| 用户价值与商业潜力 | 今天用户是自己 + 科研圈；商业是赌注，已写清 |
| 创新性 | 生态第一次"考行为"而非"考省" |
| 生态应用 | 购晶体管 → 流片 → 容器 → 存证，全链路用 TapeOut |
| 完成度与体验 | 判卷机已出 85.30；复算一条命令 |
| Demo（≤3 分钟） | 买最便宜 NAND → 流片 → 判卷机出 85.30 → 观众当场重算 |

> 硬约束：黑客松要求使用 **X Layer 上**的 TapeOut 电路/合约/链上数据并提供地址；我们目前在 BNB Chain 侧，要参赛需先在 X Layer 落一块电路。截止 2026-12-07 23:59 UTC。

## 14 · 下一步

**主线只有一件：首矿四步。**

1. 在晶体管市场挂单买 **1 颗最便宜的可流片 NAND**（Genesis 行）；
2. 成交后对题库 **#4 与非门**一键流片（1 NAND + 0 LATCH，全场最便宜的门票，目标处理器 TapeOut ×1）；

4. 次日看第一笔 BEM 到账。

这四步的意义不在收益，而在**把"可流片到"这四个字从商品标签变成实测事实**。如果弹窗拒绝便宜料，那段原文就是最有价值的一条实验记录。
