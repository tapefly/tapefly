# TapeFly 商业模式一页纸

## 一句话

普通玩家免费入门；愿意继续挑战的人购买有主题、会更新、可验证的电路赛季；品牌、社区和教育机构付费赞助同一个挑战系统。

## 为什么现在不做“大而全”

TapeFly 当前只有一种核心行为：

> 搭身体 → 接 NAND 大脑 → 看它自己飞 → 失败回放 → 改一根线 → 验证 → 可选流片。

收入必须围绕这个循环，而不是同时承诺 Steam 销售、硬件销售、NAND 投机和教育采购。

## 用户

### C1：普通游戏玩家

- 喜欢搭建、自动化、物理谜题和程序化行为。
- 不一定懂电路，也不一定持有加密货币。
- 先用 itch 或网页免费体验。

他们的问题：

> “我能不能不看攻略，自己做出一个真的会找路、会记忆、会犯错的机器？”

### C2：电路和 AI 挑战玩家

- 已经完成基础关卡。
- 愿意研究门数、层数、记忆状态和排行榜。
- 想保存作品、参与主题赛、拿到可公开验证的电路。

他们的问题：

> “我的设计是否真的更好，还是只是碰巧过了一关？”

### C3：赞助方

- X Layer / TapeOut 生态项目。
- AI、开发者工具和游戏社区。
- 学校和编程教育机构。

他们的问题：

> “有没有一个真实的场景，让普通用户第一次理解电路，并产生可衡量的参与和结果？”

## 收入模型

### 1. 免费层

包含：

- Workshop 第一章和基础关卡。
- 浏览器和 itch 无钱包游玩。
- 本地存档。
- 基础回放、失败诊断和芯片视图。

目的：

- 降低获客成本。
- 让用户在不懂钱包和电路时先体验结果。
- 给 Steam、教育和赞助合作提供漏斗入口。

### 2. Player Season Pass

建议首轮测试价格：`US$4.99 / 四周赛季`。

包含：

- 10–15 个新关卡。
- 一个主题设计约束，例如“只能用 1 位记忆”或“20 门以内”。
- 经过服务器复算的正式排行榜。
- 设计历史、派生关系和作品页。
- 可选流片折扣或纪念证书。

不能出售：

- 胜利。
- 更高门数预算。
- 更快的果蝇。
- 更高掉落率。

所有付费玩家必须使用相同规则和相同门数限制。付费购买的是内容、组织和公开验证，不是竞争优势。

为什么用户付钱：

- 已玩完免费内容，想继续挑战。
- 新关卡每赛季更新，单次价格低于一款完整游戏。
- 想让自己的设计进入正式榜和公开作品页。

为什么持续使用：

- 每月新约束。
- 固定种子排行榜。
- 人类和 AI 共用规则。
- 设计可以保存、派生、复盘和比较。

### 3. Sponsored Challenge

首轮测试报价：`US$500–2,000 / 两周期主题挑战`。

交付给赞助方：

- 一个品牌主题关卡或规则约束。
- 面向玩家的公开挑战页。
- 服务器复算后的排行榜。
- 不暴露用户隐私的参与和完成数据。
- 可复算的获奖大脑。
- X Layer 流片或纪念 Circuit 方案。

为什么赞助方付钱：

- 获得一个具体、可量化的用户参与场景。
- 不是买广告曝光，而是拿到真实提交和可验证结果。
- X Layer / AI 项目需要一个让普通用户第一次使用电路的入口。

适合的首批赞助方：

- X Layer 生态工具。
- AI Agent 项目。
- 游戏社区。
- 编程训练营和 Web3 教育项目。

### 4. Optional Tape-out

建议只在替换处理器可用后开放。

收费构成：

```text
用户支付 = NAND 成本 + 协议/处理器费用 + gas + TapeFly 服务费
```

TapeFly 服务费建议首轮测试：

- 普通设计：`US$3–5`。
- 赛季冠军或特殊封装：更高价格，但必须单独说明。

当前不能收费：

- 首个 TapeFly 自有处理器价格单位错误。
- 玩家正常购买 NAND 的成本不可用。
- 必须等待替换处理器部署并完成真实流片测试。

## 为什么不先靠 Steam

Steam 可以扩大普通玩家入口，但当前仍在准备阶段：

- 无最终桌面发行包。
- 无手柄和 Steam Deck 完整验收。
- 无普通 PC 玩家留存数据。
- Steam 版不能包含钱包、代币或 NFT。

因此 Steam 是获客路线，不是本次黑客松的当前收入。

## 单位经济模型

### Season Pass

以 `US$4.99` 为例：

| 项目 | 假设 |
|---|---:|
| 玩家支付 | US$4.99 |
| 支付渠道成本 | 约 US$0.45 |
| 服务器和存储 | 低于 US$0.10 / 活跃玩家 / 月 |
| 关卡制作 | 固定成本 |
| 首轮最低目标 | 100 名付费玩家 / 赛季 |

结论：

- 赛季制适合小团队，因为新增内容一次制作，多人重复使用。
- 避免按每局收费，否则会伤害学习和复玩。
- 不需要发行项目代币也能成立。

### Sponsored Challenge

以 `US$1,000` 为例：

| 项目 | 假设 |
|---|---:|
| 赞助收入 | US$1,000 |
| 关卡和活动制作 | 5–8 人日 |
| 服务器成本 | 低于 US$50 |
| 人力成本 | 团队自定 |

结论：

- 一个赞助活动大约相当于 200 个 `US$4.99` 赛季玩家。
- 对早期产品，B2B 赞助比等待大规模 C 端订阅更快验证收入。

## 首批商业验证目标

以下为目标，不是已实现数据：

| 指标 | 30 天目标 |
|---|---:|
| itch / 官网开始游戏 | 300 |
| 完成第 3 关 | 120 |
| 使用失败回放 | 60 |
| 完成第 5 关 | 60 |
| 加入赛季候补 | 30 |
| 愿意为赛季支付 US$4.99 | 10 |
| 赞助方有效沟通 | 2 |
| 完成真实流片演示 | 1 |

如果数据达不到：

1. 先改首次五分钟体验，不先降价。
2. 如果玩家愿意玩但不愿订阅，转向 Steam 一次性付费。
3. 如果普通玩家不愿深入，优先做学校或赞助挑战。
4. 不在留存未验证时扩大硬件计划。

## 最需要证明的三件事

1. 普通玩家能否在五分钟内理解“接线改变行为”。
2. 完成免费关卡的玩家，是否愿意为下一个赛季付费。
3. 赞助方是否愿意为一个可复算的电路挑战支付固定费用。

## 提交用短版

> TapeFly uses a free game loop to bring new users into TapeOut. Players can finish the first chapters without a wallet. A paid four-week challenge season adds new level packs, verified rankings and optional tape-out ownership. Projects and communities can sponsor themed circuits and receive real participation plus results anyone can recompute. Steam and desktop hardware are later acquisition channels, not the current revenue claim.
