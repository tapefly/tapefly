## Main long post — English

```text
Most AI agents and game characters are black boxes.

You see an action, but you cannot prove why the deployed system chose it. Public code does not prove that the hosted behavior never changed.

TapeFly starts with the opposite approach: make the whole behavior small enough to check.

Six senses become a 12-bit input.
A 50-gate NAND circuit returns a move and an escape reflex.
Because the input space is exactly 4,096 cases, anyone can verify every possible decision rather than trust a handful of samples.

This is not a concept video.

The official brain is already taped out as TapeOut Circuit #1:
• the on-chain netlist matches the public source
• all 4,096 answers were verified
• every day can be replayed
• anyone can check it through a public RPC without connecting a wallet

But verification alone does not create a game people return to.

TapeFly makes the circuit playable:
flip instincts or write readable rules,
compile them into TapeOut-compatible NAND gates,
and watch your fly try to survive today's dish.

Players can challenge friends, join weekly seasons and optionally tape out a brain they own.

The same open API is available to AI agents. Human-designed and AI-designed brains can compete under one public ruleset: which behavior is more effective, smaller or more robust?

Next: X Layer.

We will tape out the fly brain on X Layer, use public X Layer block data for the daily world seed, expose the same agent API, and operate one free arena shared by human- and AI-designed brains.

TapeOut makes circuits permanent.
TapeFly makes behavior understandable, verifiable, playable and ownable.

I'm Richard, founder of TapeFly and a previous X Layer hackathon second-prize winner. This time, we are not shipping another black box that only looks intelligent. We are shipping the proof with it.
```
